## 复现与发布

1. 使用已有Node 20+、Playwright及Microsoft Edge，运行[采集脚本](tools/capture_demo.cjs)。只允许固定公开Synthetic网址；脚本会在独立演示会话填写模拟预警和修订，不连接本地业务库。
2. 使用Pillow与免费FFmpeg运行[视频构建脚本](tools/build_video.py)，通过参数指定素材和输出目录，输出目录应位于仓库之外。
3. 构建脚本同时生成逐句SRT、时间轴和视频。缺失素材或数值不符时应停止，不修改截图数字。
4. [独立字幕文件](DEMO.zh-CN.srt)与[可复现命令](SHOWCASE.md)随文档提供。MP4不提交到Git；本轮未上传托管，发布由作者决定。
