# V2.1 可复现演示（约 10–15 分钟）

全部为 Synthetic 模拟业务。以下使用仓库附带的 `v2/demo_data/phase2_synthetic.xlsx`；没有真实经营收益或真实审批人员。页面标签来自当前代码。截图为历史验收快照，不保证每次生成的 ID、时间或预警数量相同。

## 0. 独立启动

按[首页启动命令](../../README.md#安装与启动)启动，使用尚未使用过的 `v2/runtime/portfolio-demo` 数据目录；已有该目录时换一个新名称，不删除旧目录。选择“第二阶段独立模拟演示”，操作员填“模拟运营”。此空间使用独立库，保持“业务数据”为空。不要再点两天正常/错误场景按钮，否则累计导入会改变对账值。

## 1. 导入六表

页面：“数据运营工作台 → 批次与日志”，点击“导入14天第二阶段模拟数据”。也可在“数据导入”选择 `workbook` 并上传上述 XLSX，二者选择一种即可。

预期：显示导入结果、批次和操作日志。再上传同一文件应识别重复，新增记录为 0，经营金额不增加。数据覆盖 2026-09-01 至 09-14，含负价、未知 SKU、库存、广告和退款场景；不需要外部数据下载。

## 2. 检查质量与证据

页面：“数据运营工作台 → 质量检查”。查看分类、业务影响摘要与问题明细，按批次或分类筛选，展开原始证据。负价订单 `SYNTH-BAD` 属于硬错误；`SYNTH-UNKNOWN` 的 SKU999 无成本，收入可用而利润隔离。

下载“数据质量报告（HTML）”并本地打开，核对页面筛选与报告明细。“包含已失效异常”只影响历史明细，不改变当前摘要。不要把异常条数当成不同记录数，也不要称其为损失金额。

## 3. 人工审核（主演示路线）

页面：“数据运营工作台 → 异常审核”，选 `SYNTH-BAD` 对应异常，结论选“确认”，说明填“模拟核查：负单价仍需凭证修订”，保存。

预期：审核记录及说明留存，负价记录仍隔离，金额不变。确认不等于修复；不要演示为“一键清洗正确数据”。这条路线可保持下面的未修订金额，便于对账。

## 4. 经营分析

页面：“经营分析”，日期 2026-09-01 至 09-14，平台/SKU/国家/状态均选全部，退款观察截止日设 2026-10-10（演示时今天应晚于该日）。

未修订且只导入一次该场景时：折后销售额 **1364 USD**，有效完成订单 **71**，成本已知销售额 **1344 USD**，未知成本收入 **20 USD**；选择 SKU001 销售额为 **924 USD**。核对趋势、来源明细和 JSON 下载。国家维度无广告字段，不展示虚构国家 ROAS 或广告分摊。

## 5. 预警查看与处理

页面：“智能预警”，检测参考日设 2026-10-10，点击“运行规则检测”。这一步实际写入检测记录，刷新或生成日报不会代替它。

预期：可见符合阈值的历史触发证据、规则版本、指标和限制；数据不足的规则会跳过，不能宣称 13 条均触发。选择一个预警，填写模拟核查说明后保存处理状态；“已解决”表示处理记录，不证明经营风险已消失。重复检测同周期不应产生重复待办，但会留存检测证据。

## 6. 经营日报与离线报告

页面：“经营日报”，D=2026-09-14，H=2026-10-10。范围为当前空间全部平台/SKU/国家。未修订时 D 销售 **92 USD**、订单 **5 笔**、商品毛利 **28 USD**、暂估贡献 **−8 USD**；D−1 销售 **72 USD**、订单 **4 笔**，销售环比 **+27.78%**。利润为已知成本样本，不是净利润。

查看六项 KPI、前日变化、成熟样本、质量限制。已执行步骤 5 时可见观测期截至 D 的留存预警；检测保存时间是本次操作时间，不是 9 月 14 日。未检测则显示证据不足，不能说“当日无异常”。

点击“下载 HTML 日报”，本地断网打开，核对 D/H、六项 KPI、变化、证据 ID 和建议；下载不写审核、修订或预警。改为 D=2026-09-20 可查看无匹配状态；切“业务数据”可查看空库。将 H 设为 D 可查看退款队列未成熟，不能据此认定退款改善。

## 7. 可选：凭证修订对照（在主路线之后）

页面：“数据修订”，选择 `SYNTH-BAD`，字段 `unit_price`，建议值 `20`，原因填“模拟凭证核对”，证据引用填 `SYNTH-VOUCHER-001`（模拟引用，不是已有真实凭证）。提交申请后指标不变。选中申请、填写审批说明并批准后重新质检，原始 −10 保留在版本链。

预期：全期间销售从 **1364 → 1384 USD**；D 日销售从 **92 → 112 USD**。不要再用未修订截图数值对账。预警需重新手动检测；旧证据保留，日报当前重算与旧证据可能不一致，这是应说明的时间边界。未知 SKU 成本仍未知，不因这次修订自动补齐。

## 演示限制

样例只有 14 天，不能证明长期趋势或真实企业因果。按钮不会重置已有记录；修改规则或批准修订都会改变后续结果。预警版本 ID、批次 ID、时间应以运行结果为准。多版本历史预警截图来自专门验收场景，按此基础流程不一定生成相同版本数量。完整性缺失、成本、退款限制应保留在讲解中。
