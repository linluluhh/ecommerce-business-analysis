## 本轮展示检查结果

- MP4实际时长300.00秒，1920×1080、24fps、H.264，无音轨；文件6,130,238字节（约6.13MB）。
- FFmpeg完整解码7200帧成功；Edge实际播放时间推进，并完成10个时间点跳转检查。
- 视频包含36句烧录中文字幕；完整讲稿与独立SRT使用同一时间轴。
- 75个文档相对链接通过，14张PNG存在且尺寸一致；README预览6张内嵌截图均正常加载。
- [机器可读展示验证摘要](presentation-validation.json)保存视频SHA-256与播放检查结果。此验证仅针对展示材料，不是新增应用全量测试。

## 操作发现与限制

- 订单修订批准后，销售增加20而非30：原-10被隔离，未参与原汇总。
- 质量摘要的异常条数、受影响记录数不能相加或当成财务损失。
- 修订后新库存差异仍需核实。演示不强行放行，也不修改库存来制造“全部通过”。
- 首次补拍质量页保留之前的未知SKU选项，下拉与证据出现不同步；采集断言拒绝该镜头。后按库存业务表明确筛选并重新核对正文。失败素材与日志保留在本地，不作为公开成功证据。
- 报告生成时点、经营日、退款观察日和预警保存时点分别披露；不能把历史预警当作修订后的最新检测结果。
- 平台下拉仅有Amazon，本轮不展示不存在的跨平台经营数据。
- 采集日志出现统计脚本ERR_ABORTED等非阻断请求；不包装成“所有浏览器请求零错误”。

## 如何复现展示素材

前提：已有Node 20+、Playwright、Microsoft Edge、Python/Pillow和免费FFmpeg。这里的脚本是展示辅助工具，应用本身不依赖这些视频工具；不需要付费软件。所有输出目录均应放在仓库之外。

~~~powershell
# 在仓库根目录执行；用自己的外部输出目录替换占位符。
node docs/portfolio/tools/capture_demo.cjs <外部素材目录>
# 若Playwright不在本项目依赖路径，PLAYWRIGHT_MODULE可指向现有安装。
python docs/portfolio/tools/build_video.py --capture <外部素材目录> --out <外部视频目录> --ffmpeg <FFmpeg可执行文件> --font <中文字体文件>
~~~

采集仅允许脚本中固定的公开Synthetic网址；会在自己的临时会话写入模拟预警说明和修订申请。不会重新部署，不修改SQLite结构、指标公式或13条规则。不要改成指向业务库的脚本。

构建会生成MP4、SRT、逐句时间轴和讲稿。截图比例只做等比缩放；不得修改数字来匹配旁白。若数据不符，先停止并核对实际页面。
