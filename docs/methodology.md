# 分析口径与复现说明

**基于模拟数据的业务分析项目。**

## 可复现入口
在项目根目录运行 `python scripts/run_project_v1.py`。输入固定六张raw CSV，原始哈希与manifest核对失败时停止；输出覆盖V1派生成果，不修改学习者原Notebook或Excel。第三方依赖见requirements.txt，SQLite为标准库。SQL从sql目录读取执行并与Pandas对账。旧的data_quality_progress.md是学习阶段记录，最终质检以data_quality_report.md为准。

## 主要指标
- 折前商品金额＝quantity×unit_price；折后销售额＝折前金额−整单discount，只确认completed。
- 毛利润＝折后销售额−quantity×unit_cost。成本两个月固定，无汇率处理。
- 经营贡献利润＝毛利润−订单物流费−佣金−当月确认的有效批准退款−当月已记录广告费用。
- 毛利率用总毛利÷同样本总收入；ROAS用广告归因收入÷相同已知花费样本广告费，广告收入不额外加入订单收入。
- 退款率分母为已完成有效、成本已知订单，分子为下单后12天内至少一笔有效批准退款的不同订单。观察截止2026-10-12；只使用原始模拟日期，不声称是已发生的真实售后。
- refunds.date采用确认月做利润，采用order_date做订单队列，二者用途不同。

## 数据处理
全字段重复且业务键一致才去重。大额数量/价格为待核实，不擅自修正。异常标记与标准列留在clean；quarantine另存证据；profit_orders为临时利润样本。客户ID缺失不排除收入，不猜测新老客。商品成本未知单独披露。两笔异常退款从临时统计隔离而不封顶。广告缺失费用不填0，日报缺行仅按观测固定活动模式提醒。库存异常不自动修正。

## 对账与解读
收入和费用桥梁可精确加总；SKU、平台贡献变化可与公司样本总额对账。国家不分摊无法归属的广告费，所以仅提供销售与商品毛利。销量/结构/标价/优惠按固定顺序做毛利分解，属于会计解释而不是因果模型。

缺货、促销和CPC情景可能彼此重叠，不得叠加为最终利润下降原因。固定9月规模的费用情景也不是反事实收益承诺。月度总量包含31日与30日差异；只有两个月无法判断季节性。

## AI辅助
weekly_report.py先生成确定性周报和证据包，模型只能返回白名单指标引用，数字由程序渲染。支持--ai-draft输入JSON；非法指标/自行生成数字立即失败。没有自动发邮件、联网调用或计划任务。示例AI草稿由本项目协作助手依据证据编写，验证只检查结构和数值引用，不能替代事实与业务因果审查。

## 技术与人工贡献
学习者完成Excel理解、探索及部分Notebook操作；AI协作补齐V1流水线、质量复核、报告和展示。求职时应如实说明AI参与，能解释代码和口径后再声称掌握相应能力。
