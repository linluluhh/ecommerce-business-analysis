# 统一经营指标与数据血缘

V1依据：`docs/methodology.md`、`docs/data_dictionary.md`、`scripts/run_project_v1.py` 与 `sql/01_monthly_profit.sql`，全部只读。完整指标元数据在 `metrics.py / DEFINITIONS`。价格/数量临时复核线仍为100 USD/10件；不会因第二阶段开发改变旧口径。

## 原字段与粒度

- orders：order_id 一笔单SKU订单；order_date 日粒度；quantity、unit_price、discount（整单）、shipping_fee、platform_fee；completed/cancelled；平台、国家、sku。
- products：sku、unit_cost 静态单位采购成本。
- inventory：date×sku 共享库存；opening_stock、inbound_qty、sold_qty、closing_stock。不拆平台，没有在途库存。
- refunds：refund_id 一笔申请；order_id 可多笔关联；refund_date、refund_amount、refund_status。
- ads：date×platform×campaign_id×sku；ad_spend、attributed_revenue、impressions、clicks、conversions。
- customers：customer_id、register_date；V1 new/existing 基准2026-08-01固定。

所有金额USD；Decimal计算，展示两位，原值不强制截断小数。无汇率、物流收入、工资、税费或平台补贴承担方字段，不创造这些指标。

## 指标

|指标|公式与样本|日期归属/限制|
|---|---|---|
|有效订单数|整行隔离以外的 completed 不同订单|按 order_date；cancelled 不确认收入成本|
|折后销售额|quantity×unit_price−整单discount|有效 completed，未知成本收入保留|
|成本已知销售额|成本有效且已知的有效订单销售额|与毛利使用同一订单样本|
|商品成本|quantity×unit_cost|仅已知成本，不填未知成本0|
|商品毛利|成本已知销售额−商品成本|不扣物流、佣金、退款和广告|
|商品毛利率|总毛利÷成本已知销售额|总额比率，不是单笔比率平均|
|已记录广告费用|有效 ad_spend 之和|按 ads.date；缺失/隔离不补0，不保证已收齐账单|
|退款金额|有效 approved 退款且原订单在已知成本有效范围|按 refund_date 确认期，跨月扣费用|
|12天退款订单率|下单后0–12天内至少一笔有效批准退款的不同订单÷观察满12天的已知成本有效订单|按下单队列；使用独立退款观察截止日，不能把确认月分子混入下单月分母|
|暂估经营贡献|毛利−订单物流−佣金−确认退款−已记录广告费|当前已知成本样本与费用；不是全企业财务净利润|
|数据完整率（订单可用）|有效completed订单÷可定位日期范围的原始completed订单|数据可用率代理，不证明没有漏单/未上传日期；未知成本另披露|
|成本覆盖率|已知成本销售额÷有效销售额|按收入覆盖；成本未知订单数/收入及利润订单数另列|
|ROAS|同样本广告归因收入÷对应广告费|广告归因收入不再次加订单收入；花费0或必要字段缺失不能计算|

## 缺失与覆盖

第二阶段指标服务没有可用订单、没有成本样本、没有广告费用/归因收入、没有退款账本或尚无成熟退款队列时返回 None，界面显示“数据不足”。未知成本只使对应订单利润未知，不删除有效收入。

退款账本至少有可用记录才允许将某确认期无有效退款汇总为0；这表示已提供观测账本中的0，不证明所有退款均已录入。12天队列中存在隔离退款时，退款率不可计算，避免将跨统计期的错误退款当成率改善。广告部分记录缺失时列出数量，ROAS不可计算；贡献仍可显示已记录部分样本，但利润预警跳过受影响周期。质量/成本覆盖变化时利润环比跳过。

国家筛选能计算收入和商品毛利；广告没有国家字段，不分摊广告，国家贡献/ROAS显示数据不足。订单状态筛选保留相同有效订单范围；cancelled 不产生确认经营金额。

第一阶段 `Store.metrics` 保留旧契约的临时聚合空样本0及按月已记录费用语义以兼容原测试和历史说明，使用同一事实样本和金额函数；当前所有按月界面、新看板、规则与导出统一采用更明确的 None/不足契约。没有已知成本样本时旧工作台也显示“数据不足”，不展示虚假0利润。

## 筛选、趋势及钻取

日期为首尾包含的日区间；同时应用平台、SKU、国家、订单状态与数据空间。收入/毛利按订单日，退款/广告按确认/投放日；队列退款率按筛选下单日，保留范围外但窗口内的批准退款。退款通过原订单关联平台/SKU/国家。图表、JSON导出、逐笔来源均调用同一 MetricCenter，不堆叠销售与利润。

逐笔来源包括原始记录ID、订单、日期、平台、SKU、金额、是否成本已知、源文件/批次/行号与已批准修订链。缺日趋势保留为空；没有活动日历就不能把无记录日视为零销售。
